## 👋 About me

Frontend developer focused on building **scalable, responsive, and user-centric web applications**. I come from a technical background in mechatronics — which gives me an analytical mindset and a strong eye for performance and system architecture.

I've shipped real production apps: a full delivery platform with payment integration and an institutional website focused on lead conversion. I build with React and TypeScript as my core stack, and I'm always looking to raise the bar on code quality and UI experience.

- 🌍 Based in Brazil — **open to relocation to Europe**
- 💬 Fluent in **English** and **Portuguese**
- 🚀 Currently deepening my skills in **Next.js** and **testing with Vitest/RTL**
- 🎯 Looking for my first **professional frontend opportunity**
